# 引き継ぎメモ

セッションをまたいで作業を再開するための記録。**新しいものを一番上に足す。**

- 保存は最大5件。6件目を足すときは一番下（最古）の1件を削る。
- 会話開始時に自動で読み込まれるのは**直近2件**のみ（`.claude/hooks/read-handover.sh`）。
- この見出しより下の `## ` 見出しが1件を表す。書式を変えると読み込みが壊れる。
